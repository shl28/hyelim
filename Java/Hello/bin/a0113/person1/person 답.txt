# 상속 & 오버라이딩 문제

## 📌 문제 설명

다음 조건을 만족하는 상속 관계 프로그램을 작성하세요.

---

## 1️⃣ 부모 클래스 Person

아래의 멤버를 가지는 `Person` 클래스를 작성하세요.

### 🔹 필드

- `String name`: 이름
- `int age`: 나이

### 🔹 생성자

- 이름과 나이를 매개변수로 받아 초기화하는 생성자

### 🔹 메서드

- **`introduce()`**
  - `"이름입니다."` 형식으로 출력
  
- **`work()`**
  - `"이름이(가) 일을 합니다."` 출력
  
- **`displayInfo()`**
  - `"이름: 이름, 나이: 나이"` 출력

---

## 2️⃣ 자식 클래스 Student

`Person` 클래스를 상속받아 `Student` 클래스를 작성하세요.

### 🔹 필드

- `String major`: 전공

### 🔹 생성자

- 이름, 나이, 전공을 매개변수로 받아 초기화
- **부모 생성자를 반드시 호출할 것** (`super()` 사용)

### 🔹 메서드

- **`work()` 메서드를 오버라이딩**
  - `"이름이(가) 공부를 합니다."` 출력
  
- **`study()`**
  - `"이름이(가) 전공를 공부합니다."` 출력
  
- **`displayInfo()` 메서드를 오버라이딩**
  - 부모의 `displayInfo()` 호출 (`super.displayInfo()`)
  - 전공 정보 추가 출력 (`"전공: 전공"`)

---

## 3️⃣ 자식 클래스 Teacher

`Person` 클래스를 상속받아 `Teacher` 클래스를 작성하세요.

### 🔹 필드

- `String subject`: 담당 과목

### 🔹 생성자

- 이름, 나이, 과목을 매개변수로 받아 초기화
- **부모 생성자를 반드시 호출할 것** (`super()` 사용)

### 🔹 메서드

- **`work()` 메서드를 오버라이딩**
  - `"이름이(가) 수업을 합니다."` 출력
  
- **`teach()`**
  - `"이름이(가) 과목을 가르칩니다."` 출력
  
- **`displayInfo()` 메서드를 오버라이딩**
  - 부모의 `displayInfo()` 호출 (`super.displayInfo()`)
  - 과목 정보 추가 출력 (`"과목: 과목"`)

## 💡 힌트

### 힌트 1: 상속 문법

```java
class 자식클래스 extends 부모클래스 {
    // ...
}
```

### 힌트 2: 부모 생성자 호출

```java
public Student(String name, int age, String major) {
    super(name, age);  // 부모 생성자 호출
    this.major = major;
}
```

### 힌트 3: 메서드 오버라이딩

```java
@Override
public void work() {
    // 자식 클래스의 구현
}
```

### 힌트 4: 부모 메서드 호출

```java
@Override
public void displayInfo() {
    super.displayInfo();  // 부모 메서드 호출
    // 추가 출력
}
```

### Person.java

```java
/**
 * 부모 클래스: Person
 */
class Person {
    // 필드
    String name;
    int age;
    
    // 생성자
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    // 메서드
    public void introduce() {
        System.out.println(name + "입니다.");
    }
    
    public void work() {
        System.out.println(name + "이(가) 일을 합니다.");
    }
    
    public void displayInfo() {
        System.out.println("이름: " + name + ", 나이: " + age);
    }
}
```

### Student.java

```java
/**
 * 자식 클래스: Student
 * Person을 상속받음
 */
class Student extends Person {
    // 필드
    String major;
    
    // 생성자
    public Student(String name, int age, String major) {
        super(name, age);  // 부모 생성자 호출
        this.major = major;
    }
    
    // work() 메서드 오버라이딩
    @Override
    public void work() {
        System.out.println(name + "이(가) 공부를 합니다.");
    }
    
    // Student만의 메서드
    public void study() {
        System.out.println(name + "이(가) " + major + "를 공부합니다.");
    }
    
    // displayInfo() 메서드 오버라이딩
    @Override
    public void displayInfo() {
        super.displayInfo();  // 부모 메서드 호출
        System.out.println("전공: " + major);
    }
}
```

### Teacher.java

```java
/**
 * 자식 클래스: Teacher
 * Person을 상속받음
 */
class Teacher extends Person {
    // 필드
    String subject;
    
    // 생성자
    public Teacher(String name, int age, String subject) {
        super(name, age);  // 부모 생성자 호출
        this.subject = subject;
    }
    
    // work() 메서드 오버라이딩
    @Override
    public void work() {
        System.out.println(name + "이(가) 수업을 합니다.");
    }
    
    // Teacher만의 메서드
    public void teach() {
        System.out.println(name + "이(가) " + subject + "을 가르칩니다.");
    }
    
    // displayInfo() 메서드 오버라이딩
    @Override
    public void displayInfo() {
        super.displayInfo();  // 부모 메서드 호출
        System.out.println("과목: " + subject);
    }
}
```

## 📝 풀이 설명

### 1. 상속 구조

```
        Person (부모 클래스)
            ▲
            │ extends
    ┌───────┴───────┐
    │               │
 Student          Teacher
(자식 클래스)    (자식 클래스)
```

### 2. 핵심 포인트

#### ✅ 상속 (extends)

- `Student`와 `Teacher`는 `Person`을 상속받음
- 부모 클래스의 필드와 메서드를 자동으로 상속받음

#### ✅ super() 사용

- 자식 클래스의 생성자에서 부모 생성자를 반드시 호출
- 첫 번째 줄에 위치해야 함

#### ✅ 메서드 오버라이딩

- `work()` 메서드: 각 자식 클래스에서 다르게 구현
- `displayInfo()` 메서드: 부모 메서드 호출 후 추가 정보 출력

#### ✅ super.메서드명()

- 오버라이딩된 메서드에서 부모 메서드를 호출할 때 사용
- `super.displayInfo()`로 부모의 `displayInfo()` 호출
